# Загрузчик архива Google Apps Script

1. Создайте новый проект на https://script.google.com/ под аккаунтом владельца архивной папки.
2. Замените содержимое `Code.gs` кодом из этого каталога.
3. В настройках проекта включите показ файла манифеста `appsscript.json` и замените его содержимое.
4. Выберите «Развернуть» → «Новое развертывание» → «Веб-приложение».
5. Выполнять от имени: владелец проекта.
6. Доступ: все пользователи, включая анонимных.
7. Разрешите скрипту доступ к Google Drive, внешним запросам и управлению пользователями Firebase Authentication.
8. Передайте URL развертывания, заканчивающийся на `/exec`, для подключения к сайту.

Публичный endpoint проверяет Firebase ID token и поле `approved` профиля перед загрузкой.
Неподтвержденные пользователи не могут сохранять файлы в папку.

Удаление заявки также проходит через endpoint: сервер повторно проверяет роль администратора
и разрешает удалять из Firebase Authentication только неподтвержденные профили с ролью `member`.
