# КПЦ Симбирск — генератор и база ориентировок

Статический PWA-проект с общей базой Firebase для подтвержденных пользователей.

## Что умеет
- Работает на телефоне и компьютере.
- Устанавливается на главный экран как приложение (если браузер поддерживает PWA).
- Автосохраняет текстовый черновик в браузере.
- Показывает живой предпросмотр.
- Создаёт PDF на устройстве без Apps Script.
- Сохраняет созданные ориентировки в общей базе Firestore.
- Разделяет активные поиски и архив по ПСС и ПТП.
- Поддерживает вход через Google и по email с подтверждением доступа администратором.

## Архив на Google Drive

Архивирование создаёт PDF с ориентировкой, заметками и фотографиями, загружает его в папку
`10UIpRNpDoHZEb27ZD-AkhS0OQHgswBvN`, а в Firestore оставляет только компактную запись и ссылку.

Для работы функции в проекте Google Cloud `kpc-simbirsk` должен быть включён Google Drive API.
Пользователь, выполняющий архивирование, входит через Google и должен иметь право добавлять файлы
в папку архива. Просмотр PDF наследует настройки доступа родительской папки.

## Публикация
Проект публикуется через GitHub Pages из ветки `main`, корень репозитория.

## Firebase

- Проект: `kpc-simbirsk`.
- Правила базы: `firestore.rules`.
- Первый администратор создается при первом входе владельца через Google.
- Публикация правил: `npx firebase-tools deploy --only firestore:rules,firestore:indexes`.

## Важное про офлайн

Черновик и ранее загруженные файлы интерфейса сохраняются локально. Авторизация, общие ориентировки и изменение записей требуют подключения к интернету.
