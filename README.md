# КПЦ Симбирск — офлайн-генератор ориентировок

Это статический PWA-проект: после первого успешного открытия сайт кешируется и может работать без интернета.

## Что умеет
- Работает на телефоне и компьютере.
- Устанавливается на главный экран как приложение (если браузер поддерживает PWA).
- Автосохраняет текстовый черновик в браузере.
- Хранит выбранное фото локально в IndexedDB.
- Показывает живой предпросмотр.
- Создаёт PDF полностью на устройстве — без Google Drive, Apps Script и сервера.
- Исходные данные никуда не отправляются.

## Файлы
- `index.html` — интерфейс.
- `styles.css` — адаптивная верстка.
- `app.js` — предпросмотр, офлайн-хранилище и локальная генерация PDF.
- `template.jpg` — утвержденный фон ориентировки.
- `manifest.webmanifest` — установка PWA.
- `sw.js` — офлайн-кеш.
- `icon-192.png`, `icon-512.png` — иконки приложения.

## Как проверить локально на компьютере
Service Worker не работает при открытии `index.html` двойным щелчком (`file://`).
Запустите простой локальный сервер, например:
`python -m http.server 8080`
и откройте `http://localhost:8080`.

## Как опубликовать бесплатно
Подойдут GitHub Pages, Cloudflare Pages, Netlify или любой HTTPS-хостинг статических файлов.
Для PWA нужен HTTPS (исключение — localhost).

### Вариант GitHub Pages
1. Создайте репозиторий.
2. Загрузите все файлы из папки проекта в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Откройте выданную HTTPS-ссылку один раз при наличии интернета.
5. После установки/кеширования приложение будет открываться без сети.

## Важное про офлайн
Первый запуск должен пройти при интернете, чтобы браузер скачал файлы приложения.
После этого форма, шаблон, сохраненный черновик, фото и генерация PDF работают локально.

## Подстройка координат
Все координаты текста и фото находятся в `app.js` внутри `renderText()` и `coverDraw(...)`.
Исходные координаты привязаны к шаблону 1024×1536 и автоматически масштабируются к A4-канвасу.

Если конкретное поле нужно подвинуть:
`drawValue(value('height'), 121, 951, 18, ...)`
где первые два числа — X и Y в координатах исходного шаблона.
