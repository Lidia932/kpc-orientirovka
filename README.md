# КПЦ Симбирск — офлайн-генератор ориентировок

Это статический PWA-проект: после первого успешного открытия сайт кешируется и может работать без интернета.

## Что умеет
- Работает на телефоне и компьютере.
- Устанавливается на главный экран как приложение (если браузер поддерживает PWA).
- Автосохраняет текстовый черновик в браузере.
- Показывает живой предпросмотр.
- Создаёт PDF на устройстве без Apps Script.
- Исходные данные не отправляются на внешний сервер.

## Публикация
Проект публикуется через GitHub Pages из ветки `main`, корень репозитория.

## Важное про офлайн
Первый запуск должен пройти при интернете, чтобы браузер скачал файлы приложения. После этого интерфейс и закешированные ресурсы доступны без сети.
